\section{Introduction and scope}
\label{sec:intro}

FrutaMIDI is a USB MIDI controller that turns touches on conductive objects
(fruit, plants, water) into MIDI notes, using a Raspberry Pi Pico and an MPR121
capacitive sensor. It is built either on a breadboard or on a single-sided PCB
in \texttt{hardware/}.
