\section{Limitations}
\label{sec:limitations}

\paragraph{No hardware tests.} Nothing has been built, flashed, powered or
measured. Building and measuring hardware is out of scope for this project
(risk R-004, ``Certain'', ``High'') \ev{management/RISKS.md}. Every
\lbl{[PHYSICAL]} requirement is therefore PARTIAL or NOT RUN, and no statement in
this report means that the hardware works.

\paragraph{Analysis-only results.} The following results rest only on
calculation, simulation, design-rule checks or host tests:
latency and jitter (REQ-014/015); VBUS range and current (REQ-018/019); I\textsuperscript{2}C
rise time and logic levels (REQ-026/041, REQ-024); electrode ESD (REQ-023);
sensitivity with the series resistors (\lbl{SIMULATION}); ERC/DRC/parity and
home-etch rules; firmware behaviour (host tests on a copy of the loop order);
sampler behaviour (headless Chrome with a stubbed Web MIDI API).

\paragraph{Open FAILs and accepted risks.} REQ-018 (4.40\,V low-power-port VBUS minimum below the Pico's recommended 4.50\,V; documented deviation, ADR-016); REQ-032 (BOM upper bound
37.72\,EUR $>$ 30\,EUR after CR-002, prices mostly \lbl{ASSUMPTION}; increase
accepted for ESD safety, ADR-019 D-3); REQ-040 (wrong JP1
position exceeds MPR121 input ratings on an unpowered module; accepted risk R-007);
R-006 (at 8\,kV contact the 7.27\,kV across each resistor exceeds its 4.08\,kV
rating, and the pin current exceeds the inferred limit by 1.65$\times$; accepted,
ADR-019 D-1).

\paragraph{Main assumptions} (each to be retired by the plan in
Section~\ref{sec:validation}):
\begin{itemize}[noitemsep]
  \item Component prices (BOM, REQ-032) \ev{reports/systems/budgets.md}.
  \item Electrode capacitance: objects up to about 500\,pF (REQ-037); 1\,m lead
        30--50\,pF; hand 100--300\,pF \ev{reports/electronics/analysis.md}.
  \item ESD: $\pm$4\,kV target following IEC 61000-4-2 level 2 (the standard was not
        read); MPR121 pin limit 1.33\,A inferred from HBM 2\,kV; electrode discharge
        model; the breakdown models of the gap rule and the IEC 60664-1 Table F.2
        values (recalled, not re-read, EE-S25); the resistor chart reading
        ($\pm$5\,\%); a 1.2/50\,\textmu s rating taken as conservative for the
        $\approx$0.54\,\textmu s pulse; the 3k3 MBE 0414 price equal to its sibling
        values (EE-S26).
  \item Board currents (upper bounds), Schottky diode drop and regulator
        efficiency \ev{reports/systems/budgets.md}.
  \item I\textsuperscript{2}C bus capacitance; Pico pin capacitance; in the
        electronics calculation, RP2040 VIL 0.8\,V and VOL 0.4\,V and BSS138
        $R_{DS(on)} \le 10\,\Omega$ (T-055).
  \item MIC5225 typical dropout from a search extract only
        \ev{reports/electronics/analysis.md}.
  \item Firmware timing: loop period ``well under 15\,ms'', button bounce
        $<$ 10\,ms, header and pot pin sizes for the 1.0\,mm holes
        \ev{reports/firmware/coverage.md}.
\end{itemize}

\paragraph{Process limitations.} Requirements are draft-6 (T-070), not baselined.
The independent re-review of the CR-002 changes is reported in
Section~\ref{sec:cr002-review}. The committed interface-check output predates the v1.2
board label (1 expected FAIL, \texttt{pcb.label\_v1.2}); a re-run on 8394b41 gives
80/80 PASS but is recorded only in the T-072 handoff folder
(Section~\ref{sec:electronics}). Some
user-documentation statements (prices, OS behaviour, etching process values) are
not traced to a source (documentation handoffs T-030 to T-035).
