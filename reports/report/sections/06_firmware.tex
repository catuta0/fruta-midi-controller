Sources: \ev{reports/firmware/coverage.md} and the T-040 to T-043 handoffs in

\subsection{Design}
\begin{itemize}[noitemsep]
  \item One sketch \nolinkurl{firmware/FrutaMIDI/FrutaMIDI.ino} with host-testable
        header-only logic \texttt{fm\_*.h}: scales (\texttt{fm\_scales.h}, English
        names), button (\texttt{fm\_button.h}), debounce, aftertouch, potentiometer,
        non-blocking LED blinker (\texttt{fm\_blink.h}), MPR121 burst reads
        (\texttt{fm\_mpr121.h}).
  \item Pads: Note On at velocity 100 on channel 1 by default; Note Off always
        carries the stored note; debounce is a \qty{15}{\milli\second} lockout per
        pad.
  \item Aftertouch: Polyphonic Key Pressure 0--127 from delta 12--120; one 0 is
        sent before Note Off and on a fall to the floor (T-041).
  \item Scales: 6, Drum Rack (36--47, octave ignored) default; octave $-2..+2$ by
        potentiometer with 0.7-zone hysteresis.
  \item Button: long press $>$ \qty{800}{\milli\second} recalibrates (releases all
        notes, restarts sensors, 3 blinks); short press selects the next scale.
  \item LED patterns are non-blocking: pads stay live while the LED blinks (T-041).
        \texttt{startSensors()} still blocks the loop during a user-requested
        recalibration (kept by decision; duration to be measured).
  \item MPR121 configuration: AUTOCONFIG with USL/TL/LSL = 200/180/130 at design
        VDD 3.2\,V and SCTS = 0 (ADR-010, ADR-011, \lbl{SOURCE} MPR121 datasheet
        S-006); I\textsuperscript{2}C stays at \qty{400}{\kilo\hertz}; run-based
        burst reads (worst mask 42 bus bytes in 8 transactions, \lbl{CALCULATION})
        \ev{reports/systems/budgets.md}.
\end{itemize}
