\begin{abstract}
FrutaMIDI is a USB MIDI controller that sends notes when a user touches conductive
objects wired to a Raspberry Pi Pico and an Adafruit MPR121 capacitive sensor
module, built on a breadboard or on a single-sided home-etched PCB.
This report collects the requirements, decisions, interfaces, analyses and host
tests for FrutaMIDI. \textbf{Version 1.3} (change request CR-003,
Section~\ref{sec:cr003}) converts the PCB to surface-mount parts on one copper
layer on the component side, for home chemical etching without drilling: 4
mounting holes remain instead of 133. The electrode resistors become standard
2512 chip resistors whose survival of a 4\,kV discharge is not proven, a choice
the user accepted to keep the core BOM at 14.84--16.84\,EUR excluding VAT and
shipping (\lbl{CALCULATION}). An independent review (T-102) found the first
layout not ready for a first build; its fifteen findings were fixed or ruled
(ADR-028). The sections after Section~\ref{sec:cr003} keep the v1.2 analyses for
traceability. Version 1.2 (change request CR-002) replaced the
electrode series resistors by pulse-rated parts lying flat. By analysis of the
design files, a \qty{4}{\kilo\volt} contact discharge should then neither arc
across a resistor nor exceed its pulse rating; this has not been tested. A
manager PCB design review then widened the JP1 solder-jumper gaps, enlarged the
screw-terminal pads, tied the potentiometer tabs to AGND and added a 100\,nF
wiper filter (ADR-021). A final independent re-review of these changes (T-079)
found no critical or major issue (verdict release-ready); its seven findings were
fixed or accepted (ADR-022), among them a 0.9\,mm drill for C1 and a plastic knob
on an insulated shaft for the potentiometer (risk R-011).
Section~\ref{sec:changes} lists the changes since
the V1\_BASELINE release. Every number is copied from a cited project
file with its label. \textbf{No part of the hardware has been built or measured}:
analyses, simulations, design-rule checks and host tests are not hardware
validation, and the physical validation plan in Section~\ref{sec:validation}
lists what remains to be measured.
\end{abstract}
