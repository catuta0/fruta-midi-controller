\begin{abstract}
FrutaMIDI is a USB MIDI controller that sends notes when a user touches conductive
objects wired to a Raspberry Pi Pico and an Adafruit MPR121 capacitive sensor
module, built on a breadboard or on a single-sided home-etched PCB (v1.1).
This report collects the requirements, decisions, interfaces, analyses and host
tests at revision \texttt{72f67f0}. Every number is copied from a cited project
file with its label. \textbf{No part of the hardware has been built or measured}:
analyses, simulations, design-rule checks and host tests are not hardware
validation, and the physical validation plan in Section~\ref{sec:validation}
lists what remains to be measured.
\end{abstract}
