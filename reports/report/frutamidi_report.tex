\begin{abstract}
FrutaMIDI is a USB MIDI controller that sends notes when a user touches conductive
objects wired to a Raspberry Pi Pico and an Adafruit MPR121 capacitive sensor
module, built on a breadboard or on a single-sided home-etched PCB (v1.2).
This report collects the requirements, decisions, interfaces, analyses and host
tests for FrutaMIDI v1.2. Version 1.2 (change request CR-002) replaces the
electrode series resistors by pulse-rated parts lying flat. By analysis of the
design files, a \qty{4}{\kilo\volt} contact discharge should then neither arc
across a resistor nor exceed its pulse rating; this has not been tested. A
manager PCB design review then widened the JP1 solder-jumper gaps, enlarged the
screw-terminal pads, tied the potentiometer tabs to AGND and added a 100\,nF
wiper filter (ADR-021).
Section~\ref{sec:changes} lists the changes since
the V1\_BASELINE release. Every number is copied from a cited project
file with its label. \textbf{No part of the hardware has been built or measured}:
analyses, simulations, design-rule checks and host tests are not hardware
validation, and the physical validation plan in Section~\ref{sec:validation}
lists what remains to be measured.
\end{abstract}
