# CR-003: Surface-mount conversion for home chemical etching (FrutaMIDI v1.3 candidate)

- Requester: user (chat, 2026-11-09: boards will be made at home by chemical etching; through-hole is rejected, "tenta passar tudo para smd", including surface-soldering the Pico).
- Date opened: 2026-11-09. Baseline: V1.2 (tag v1.2.0, 193d6ae); work branch `change/CR-003` from main 8e963d0.

## Reason
The user etches boards at home and does not want to drill them. V1.2 has 133 drilled holes (MEASUREMENT, frutamidi.drl). The goal is to remove as many holes as possible, ideally all except mounting holes.

## Impact analysis (before design work)
- Requirements:
  - REQ-027 (through-hole only, copper on B.Cu) is reversed by this request and must be rewritten by systems.
  - REQ-029 (home-etch rules): track and clearance rules stay; drill and ring rules apply only to remaining holes; SMD pad rules are new.
  - REQ-023 (ESD): the main technical risk. CR-002 fixed flashover across R1-R12 with a 13.04 mm copper gap and a pulse-rated DIN0414 part. A chip resistor has a far smaller gap than the 3.5 mm rule at 4 kV (CALCULATION, CR-002), so the part or topology must be re-derived.
  - REQ-025 (both module revisions, JP1, configuration wires), REQ-028 (100 x 70 mm), REQ-031 (pin map), REQ-032 (cost, already FAIL), REQ-036 (manual).
- Parts / BOM: every line changes or needs a decision.
  - A1 Pico: surface-soldered, sockets removed.
  - A2 Adafruit 1982: a through-hole breakout; surface-soldered pins. A bare MPR121 is to be assessed against the home-etch rules.
  - R1-R12, R13-R16, C1: SMD parts.
  - J2 screw terminals, RV1, SW1: mechanical parts that carry force on etched copper.
  - J1 and JP1: configuration wires and solder bridge.
- PCB: full re-layout. Components move to the copper side, which changes the transfer mirroring and the silkscreen. There is no solder mask, so bare copper under the Pico and the module must be checked against their exposed underside pads.
- Interfaces: footprints and mounting change in INTERFACES.json; the pin map should not change.
- Firmware: no change expected while the pin map holds.
- Documents: hardware/README.md, manual, report, requirements, risks; rules checks in sim/systems and sim/electronics.
- Sockets are lost: a failed Pico or module must be desoldered from the surface.

## Acceptance criteria
- Hole count reduced, with every remaining hole justified.
- Pico and module footprints checked against sourced dimensions, not memory.
- REQ-023 re-derived for the SMD electrode path, or the loss of margin stated and accepted by the user.
- ERC 0, DRC 0, schematic parity 0; rules checks updated and re-run.
- Old versus new comparison table; independent re-review of the changed outputs.
- Nothing is claimed as hardware-validated.
