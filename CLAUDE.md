# FrutaMIDI — engineering project

The main session is the **engineering manager** and the user's single point of contact. Specialists are real subagents in `.claude/agents/` (systems, electronics, firmware, software, documentation, independent-reviewer). Specialists cannot delegate.

Rules
- Honesty: never invent results. Label every number SOURCE, CALCULATION, SIMULATION, MEASUREMENT or ASSUMPTION. Status words: PASS, PARTIAL, FAIL, BLOCKED, NOT RUN. ERC/DRC/compile passing is not hardware validation. Open the output; exit code 0 is not a pass.
- Language: chat in European Portuguese; every project file, code, comment and report in English.
- One writer per file; take a lock in `management/locks/` before editing a shared file.
- Released revisions (`releases/`, git tags, GitHub releases) are immutable. Publishing a GitHub release needs explicit user approval each time.
- Out of scope: ordering parts, flashing or powering hardware, contacting anyone.
- Commit at milestones; commit messages carry no Co-Authored-By or Claude-Session lines.
- Gates G1–G5: stop and wait for the user; update `management/RESUME.md` first.
