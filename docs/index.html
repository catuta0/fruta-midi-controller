FrutaMIDI Sampler

Recebe MIDI do FrutaMIDI (ou de qualquer controlador) e toca sons. Funciona no Windows e no Mac com o Chrome ou o Edge; o Safari não suporta Web MIDI.

A procurar MIDI…

Trocar o som de um pad: arrasta um ficheiro de áudio (wav, mp3, aiff, m4a) para cima dele. Mudar a nota de um pad: carrega em “aprender” e toca na fruta. Sem hardware: teclas 1234 / QWER / ASDF. As notas sem pad (escalas melódicas do firmware) tocam no sintetizador; o aftertouch abre o filtro. Os samples arrastados só ficam até fechares a página; as notas aprendidas ficam guardadas. Windows: se o FrutaMIDI aparecer como “ocupado”, fecha o DAW (ou outro separador com esta página) e recarrega.
