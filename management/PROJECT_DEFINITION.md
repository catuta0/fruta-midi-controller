# Project definition — FrutaMIDI

Status: collected in Phase A on 2026-10-30. This is a starting assumption, not a verified specification.

## Product / system
FrutaMIDI: a USB MIDI controller with 12 capacitive touch inputs (expandable to 24) in the style of the Playtronica Playtron. Touching a fruit, plant, glass of water or other conductive object wired to an input sends a MIDI Note On/Off; touch intensity is sent as polyphonic aftertouch. A button cycles scales / recalibrates; a potentiometer shifts octave. Sound is produced on the host (browser sampler included, or any DAW).

## Context
- Indoor use at home or on a small stage, by one person (non-technical end user; the builder is technical).
- Host: laptop running Windows 10/11 (primary end user) and macOS; class-compliant USB MIDI, no drivers.
- Environment: room temperature, no vibration, altitude or radiation requirements. Users touch electrodes directly (USB-powered, 3.3 V on electrodes).

## Hard constraints
- Bill of materials target: about 25–30 EUR (ASSUMPTION from earlier sessions; to be confirmed in requirements).
- PCB: single-sided, 100 x 70 mm, home-etched (toner transfer or positive photoresist), through-hole only, no vias.
- Power: USB bus power only.
- Interfaces: USB (micro-USB on the Pico), 14 screw terminals at 5.08 mm pitch (GND, E0–E11, GND).

## Bought-in parts / existing blocks not to redesign
- Raspberry Pi Pico family (Pico, Pico W, Pico 2, Pico 2 W), socketed.
- Adafruit MPR121 breakout, product 1982 (both the original and the STEMMA QT revision), socketed.
- Existing work in this repository (release v1.0.0 published, v1.1 on `main`): firmware `firmware/FrutaMIDI/FrutaMIDI.ino`, browser sampler `docs/index.html`, KiCad project `hardware/` generated by `hardware/scripts/`. These are the starting revision, not verified baselines.

## Toolchain
KiCad (+ Python scripting), arduino-cli / PlatformIO, Python, LaTeX.

## Deliverables
- Schematic + PCB (single-sided, home-etch rules), with electrical calculations and ERC/DRC.
- Bill of materials.
- Firmware, with host-side unit tests.
- Technical report (LaTeX source + PDF) and user/assembly manual.
